The hardware ladder

Keep this mental model in view

Read a one-cycle pipeline

The directed simulator and black-box reference model agree on every edge below. This trace teaches one valid-only pipeline; the exhaustive and mutation gates establish broader evidence for this exact module contract.

Validity rule: sum is meaningful only when out_valid=1. A held numeric value during an invalid cycle is not a transaction.

Nonblocking rule: all right-hand sides read pre-edge values; all <= updates become visible together after the edge. The lines do not execute as software-like “first, then” state changes.

always_ff @(posedge clk) begin
  if (rst) begin
    pending_valid <= 1'b0;
    pending_sum   <= 9'd0;
    out_valid     <= 1'b0;
    sum           <= 9'd0;
  end else begin
    out_valid <= pending_valid;
    if (pending_valid)
      sum <= pending_sum;

    pending_valid <= in_valid;
    if (in_valid)
      pending_sum <= {1'b0, a} + {1'b0, b};
  end
end

Signal dictionary

clk
The timing reference. State changes on rising edges.
rst
Active-high synchronous reset; effective only on a rising edge.
in_valid
Says whether a and b are a real input transaction.
out_valid
Says whether sum is a real output transaction.
interface limit
No ready exists: this toy always accepts valid input and cannot backpressure or stall.
latency
One complete cycle from accepted input to valid output.
throughput
One result per cycle when inputs arrive consecutively.

Your finish line

Your core-literacy checkpoint

  • Turn a truth table into a Boolean equation and RTL.
  • Distinguish combinational logic from registered state.
  • Predict reset, latency, bubbles, and valid outputs.
  • Explain blocking versus nonblocking assignments.
  • Describe simulation, synthesis, and a testbench.
  • Fill a precise functional, temporal, oracle, and QoR contract.
  • Describe compile → CSim → synthesis/report → CoSim.
  • Name the limits: timing closure, CDC, and QoR remain advanced.

Confirm these with the ordered artifacts and make verify; the quiz alone is not a generalized RTL or HLS credential.
