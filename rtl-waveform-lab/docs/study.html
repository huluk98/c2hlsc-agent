The simulator and independent scoreboard agree on every edge below. Read the inputs immediately before each rising edge and registered outputs immediately after it.

Signal dictionary

clk
The timing reference. State changes on rising edges.
rst
Active-high synchronous reset; effective only on a rising edge.
in_valid
Says whether a and b are a real input transaction.
out_valid
Says whether sum is a real output transaction.
latency
One complete cycle from accepted input to valid output.
throughput
One result per cycle when inputs arrive consecutively.
