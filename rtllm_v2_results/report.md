# RTLLM v2.0 run - c2hlsc-agent multi-agent RTL loop

Generated by `scripts/run_rtllm_v2.py`. Model: Claude Opus via the repo's `claude-cli`
LLM backend. Simulator: Icarus Verilog 12.0 (`iverilog -g2012` + `vvp`), no VCS/Vitis in
this environment. 50 designs, 8 parallel design agents, <=2 repair rounds per design.

> **Provenance (read before quoting these numbers).** This run predates three harness
> corrections, so it is kept as a record of that run, not as a current measurement.
>
> - **Vacuous oracles.** Four of the 43 functional passes below — `comparator_3bit`,
>   `comparator_4bit`, `sequence_detector`, `square_wave` — are passed by a module with
>   *no logic at all* (X-optimistic testbenches; see `VACUOUS_ORACLE_DESIGNS` and
>   `--empty-baseline`). They were not known at the time and are counted in the 43/50 and
>   in the 41/43 line below. Recomputing this run's own `results.jsonl` on the current
>   both-directions basis (50 designs minus the 3 unpassable minus the 4 vacuous) gives
>   **37/43 official, 36/43 strict** — the honest figure, against a reference ceiling of
>   43/43 on the same basis.
> - **Candidate admissibility.** The harness now refuses a design file containing
>   `$display`/`$finish`/etc. before compiling it. Re-checked against the RTL committed in
>   `designs/`: **none of the 50 files contains such a task**, so no pass in this table was
>   self-reported and the gate would not have changed this run's score.
> - **Backend sandboxing.** The `claude-cli` backend now runs tool-less in an empty
>   directory. During this run it was not sandboxed, so "the model never saw the testbench"
>   was enforced by the prompt alone. No evidence it was exploited; it was simply not
>   prevented.
>
> Re-run `--reference` and `--empty-baseline` on the current harness before comparing
> anything to this file.

- The repair loop converted **8** first-round failures into passes (35/50 -> 43/50), which is the whole argument for the closed verifier loop.
- On the 44 designs where the benchmark's own verified RTL passes, the agent passes 42.
- `clkgenerator`: the agent passes a testbench that the benchmark's own reference RTL fails.
- Excluding the 7 designs with a provably unsound oracle (below), the agent passes **41/43** (95.3%). *This basis is one-directional: it drops oracles that are too strict but keeps the four that are vacuous (see the provenance note). It reads high.*
- Wall clock: 88 agent-minutes across 8 workers (rtllm_v2_run).
