## 2. How much does the *same* configuration move between runs?

`runs/agent` and `runs/confirm` are the same configuration executed twice. This is
the single most important number for reading every other table: it is the noise floor.

- run A: **45/50**, run B: **46/50**
- designs that flipped: **3** (1 A-only, 2 B-only)
- exact McNemar p = **1.000** — the two runs are statistically indistinguishable, as they should be
- non-deterministic designs: `LIFObuffer`, `alu`, `asyn_fifo`

> **Reading rule.** A single run of one configuration carries roughly ±3 designs
> of run-to-run noise on this benchmark. Any comparison between two configurations that
> differs by that much or less is not evidence of anything.
